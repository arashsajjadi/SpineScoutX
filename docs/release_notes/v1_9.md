## v1.8c correction confirmed

v1.8b incorrectly used SAM2.1 (Transformers fallback) and called it MedSAM2. v1.8c ran real
MedSAM2 (`sam2==1.1.0`, `sam2.modeling.sam2_base`, VisionServeX runtime, `MedSAM2_latest.pt`).
Result: real MedSAM2 morphometry is *weaker* than SAM2.1 (R-for dev AUROC 0.551 vs 0.687)
and equally redundant with the image grader (fusion locked-test Δ+0.000). The v1.8b SAM2.1
fallback did **not** bias the conclusion.

## Convergent conclusion (v1.4–v1.8c)

The weak-route severe ceiling is bound by **in-domain severe-label quality and label
ambiguity**, not bugs, localizer quality, MIL, external data, SSL, larger backbones, or
segmentation-morphometry. The only remaining lever is expert re-annotation of the v1.7
704-case review pack + a clean-labelled held-out test set re-read.
